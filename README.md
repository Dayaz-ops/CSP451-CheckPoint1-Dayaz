# CSP451 CheckPoint 1 - Dayaz

## Description
This project is a simple starter web page used to practice Git and GitHub workflows such as commits, branching, and pull requests.

## Installation
1. Clone the repository:
   - `git clone <repo-link>`
2. Open the folder in VS Code.
3. Open `index.html` in a browser.

## Usage
- Open `index.html` to view the page.
- Open DevTools Console to see JavaScript output.

## Contributing
1. Create a new branch:
   - create a feature branch, make commits, and open a Pull Request.
